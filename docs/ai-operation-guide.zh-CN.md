# AI 操作指南

[English](ai-operation-guide.md) · [AI-first Vibe Coding Skill](../README.zh-CN.md)

> 让 AI 保持速度，但不悄悄扩大任务；每一步都用证据说明走到了哪里。

> **加载说明：** 这是一份可选的配套文档，不替代也不修改 `SKILL.md`，
> 不是第二个 Skill，Agent 宿主也不会自动加载它。宿主入口仍是仓库根目录的
> `SKILL.md`；需要了解工作方法和实操清单时再阅读本指南。

这是一份从真实研发工作流提炼、并为公开协作重新脱敏整理的通用操作指南。
文档不包含本机路径、凭据、内网地址、客户记录或宿主专属默认值。实际使用时，
仍应以项目规则和当前请求为准。

## 先从最小路径开始

根据请求形态选择最小动作：

| 请求类型 | 先做什么 | 不要默认什么 |
| --- | --- | --- |
| 解释、对比或调查 | 只读检查并给事实报告 | 解释请求自动授权改代码或写数据 |
| 本地实现或重构 | 建立基线、划定写集并补测试 | 本地构建通过就等于运行态或业务就绪 |
| 提交、发布、部署或写数据 | 先明确副作用边界和回滚路径 | 之前的授权自动覆盖新的外部目标 |

## 先定范围再行动

1. 用一句话写清目标，并明确涉及的仓库、分支和环境。
2. 修改前先查看当前工作树、近期历史和用户已有改动。保留脏工作区，
   不要用 reset 或清理当捷径。
3. 把本地编辑和外部副作用分开管理。commit、push、PR、tag、Release、
   部署、写库、重启和清理都是独立操作，只在请求明确授权时执行。
4. 事实不足时保持 `PENDING`，不要用“看起来合理”的猜测填空。

## 先拿证据再下结论

把以下证据流分开记录：

- **源码：** 文件、diff、分支和可达历史；
- **构建/测试：** 编译器、单测/集成测试和静态检查；
- **运行态：** 进程、容器、接口、日志和页面行为；
- **业务/数据：** 真实状态变化、记录和下游效果；
- **发布/部署/切流：** 审核过的提交、制品、环境和流量切换证据。

测试通过、构建成功、HTTP 200 或容器运行，只能证明它实际覆盖的那一小段
结论。分别报告 `RUNNING`、`PENDING`、`RECOVERING` 和 `COMPLETED`，并写明
哪些内容还没有观察到。宿主、浏览器、服务或数据源不可用时，降低证据等级，
不要把文档描述当成运行态证明。

## 安全的实现闭环

1. 先梳理用户路径、依赖和失败边界。
2. 写一份紧凑基线：目标、非目标、验收 Case 和最小安全写集。
3. 只实现能够满足一个 Case 的最小改动。
4. 运行能证明该 Case 的命令；原有行为可能回归时补回归测试。
5. 检查 diff 和生成物，确认没有意外文件、秘密、路径变化或权限扩张。
6. 用一份台账记录已改、已验证、未知项和下一步。

## 并行工作不能超载

只有真正相互独立的工作才值得拆给多个 Agent。默认先开一个；只有写集不重叠
且确实有余量时才增加并发。

每个 Wave 收口时重新计算：

```text
有效并发数 = min(
  独立任务数,
  工作区安全槽位,
  其他对话中可用的 Agent 数量,
  模型/工具/速率预算
)
```

采用短 Wave、每个写集一个负责人，并为高风险改动安排独立 Reviewer。出现冲突、
容量压力或需求不确定时暂停或合并 Wave。子 Agent 的 `DONE` 只是交接信号，不是
验收结果。

## 工具选择与降级

- 优先使用仓库自带脚本、测试和已有命令；
- 页面和用户流程用浏览器取证，机器事实在获授权时用 CLI/API/数据库工具获取；
- 运行时探测可用能力，不把某个厂商、插件或 IDE 写成通用依赖；
- 工具无法连接或宿主不可用时，说明降级原因，用当前最强的安全证据继续。

## 隐私与公开协作

分享指南、Issue 或补丁前：

- 把个人路径替换为 `<repo>`，凭据替换为 `[REDACTED_SECRET]`；
- 删除内网域名、私有 IP、客户标识、真实数据和仅组织内部适用的规则；
- 涉及来源时同时扫描当前树和可达历史；
- 把私人运行手册和公开操作原则放在不同文件中。

这份指南是共同讨论的起点，不是不可修改的统一法律。欢迎通过 Issue、Discussion
或 Pull Request 提交建议、例子和反例；最终由项目维护者结合仓库、风险和贡献者
情况决定采用哪些规则。

## 可复制的交接清单

```text
[ ] 目标、仓库、分支和环境已明确
[ ] 已检查用户改动和当前历史
[ ] 写集、非目标和副作用已划定
[ ] 独立工作有负责人，并完成容量检查
[ ] 验证命令只证明声明的那一层结论
[ ] 未知项和降级证据已记录
[ ] 没有秘密、私人路径、内网地址或真实数据
[ ] commit/push/release/deploy/写库已分别获得授权
```
