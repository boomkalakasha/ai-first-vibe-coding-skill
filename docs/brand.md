# Optional BOOMKALAKASHA brand kit

![BOOMKALAKASHA watermark](assets/brand/watermark-dark.svg)

![BOOMKALAKASHA avatar](assets/brand/avatar.png)

The local assets in `assets/brand/` and `docs/assets/brand/` are a reusable optional example: `brand-mark.svg`, `avatar.png`, `watermark-dark.svg`, and `watermark-light.svg`. They may be replaced or omitted by downstream projects. They do not establish project ownership, a support relationship, or permission to change a personal GitHub profile.

Use the dark watermark on light documentation surfaces and the light watermark on dark surfaces. Keep the square avatar at or above 40 px. The current feature branch only validates the files locally; it does not change any GitHub avatar or profile.
