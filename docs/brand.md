# Optional BOOMKALAKASHA brand kit

![BOOMKALAKASHA watermark](assets/brand/watermark-auto.svg)

![BOOMKALAKASHA avatar](assets/brand/avatar.png)

The local assets in `assets/brand/` and `docs/assets/brand/` are a reusable optional example: `brand-mark.svg`, `avatar.png`, `watermark-auto.svg`, `watermark-dark.svg`, and `watermark-light.svg`. They may be replaced or omitted by downstream projects. They do not establish project ownership, a support relationship, or permission to change a personal GitHub profile.

Use the automatic watermark for README or unknown surfaces. It follows the host colour scheme and retains an opposite-colour keyline when media queries are unavailable. Keep the explicit dark watermark for controlled light surfaces and the light watermark for controlled dark surfaces. Keep the square avatar at or above 40 px. This repository does not change any GitHub avatar or profile.
